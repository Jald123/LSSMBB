📘 Knowledge Base

What, Why, When, How

What: A calculator converting raw defect counts into a universal "Z-Score" or Sigma Level. It normalizes performance across different industries.
Why: To compare "Apples to Oranges". A hospital error rate can be compared to a factory defect rate using Sigma Level.
When:
• Define Phase: To set the baseline (current state).
• Improve/Control Phase: To validate the improvement (future state).
How: Count total units. Identify opportunities per unit. Count total defects. Map to standard table.

Requirements & Roles

  • Pre-Reqs: Stable process (check Control Charts first), Validated Measurement System (MSA passed).
  • Green Belt: Collects data, inputs into calculator, reports baseline.
  • Black Belt: Validates MSA, interprets Sigma Shift, sets D_target for sub-teams.
  • Process Owner: Provides access to data, validates "Opportunity" definition.

Standards & References

  • 1.5 Sigma Shift: Added by default to account for long-term variation.
  • World Class: 6.0 Sigma (3.4 DPMO).
  • Average: 3.0 Sigma (66,807 DPMO).
  • Fail: < 2.0 Sigma.
