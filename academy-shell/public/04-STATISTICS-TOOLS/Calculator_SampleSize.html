🔍 What Is It?
Calculates the minimum data points needed to make a statistically valid conclusion.
⏱️ When To Use?
BEFORE starting data collection. Prevents "Under-sampling" (Bias) or "Over-sampling" (Waste).
💡 Why Use It?
Sampling 5 people isn't enough. Sampling 5,000 is too expensive. Find the sweet spot.
📐 Z-Values
90% = 1.645
95% = 1.960
99% = 2.576
📐 Standard Equation
n = (Z * σ / E)²
🧠 Interpretation
Higher Confidence (99%) = Needs WAY more data.
Smaller Error (Precision) = Needs WAY more data.
🎯 Reference Values
Z-Score for 95% = 1.96.
Z-Score for 99% = 2.576.
