🛠️ Engineering Suite Guide

Detailed guidelines for each engineering module.

🛠️ TPM & OEE

What: OEE (Overall Equipment Effectiveness) is a "Zero Loss" calculation (Availability × Performance × Quality).
When: Use when a bottleneck machine is slowing down the entire factory.

How to Execute:

  1. Availability: Measure total Planned Time (e.g. 8 hour shift). Subtract ANY stops (breakdowns, changeovers).
  2. Performance: Measure Ideal Cycle Time (fastest possible speed). Compare to actual output.
  3. Quality: Count Total Parts vs Rejects (Scrap/Rework).
  4. Combine: If any factor is low, OEE drops drastically (Multiplication effect).
⚠️ Important Consideration: Avoid "Gaming the System". Do not reduce the Ideal Cycle Time to make OEE look higher. OEE should reveal losses, not hide them.

📐 Advanced MSA

What: Validates human inspectors (Visual Pass/Fail) using Kappa stats.

How to Execute:

  1. Select 30-50 parts representing the full range of defects (Good, Bad, Borderline).
  2. Have a Master (Expert) define the "True Standard" for each part.
  3. Have 2-3 inspectors measure the parts blindly (randomized order).
  4. Calculate Kappa: Are they agreeing with each other? And with the Master?
⚠️ Important Consideration: If you only select "Easy" parts (obviously good/bad), you will get a false high score. You MUST include "Borderline" samples to test true capability.

🎲 Process Simulation

What: Uses Monte Carlo methods to predict future failure rates (PPM).

How to Execute:

  1. Define the Input Distribution (Mean and Std Dev) based on historical data.
  2. Set the Specification Limits (USL/LSL).
  3. Run 1,000+ iterations to generate a virtual population.
  4. Analyze the tail defects.
⚠️ Important Consideration: Simulation is only as good as your assumptions ("Garbage In, Garbage Out"). Verify your Mean/Sigma stability first.
