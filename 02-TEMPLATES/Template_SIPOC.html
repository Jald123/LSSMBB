🔍 What Is It?
A high-level process map identifying Suppliers, Inputs, Process, Outputs, and Customers.
⏱️ When To Use?
In the Define phase, BEFORE detailed mapping. It helps define the project scope (Start/Stop).
💡 Why Use It?
Clarifies "Who gives what to whom?" ensuring no critical input or customer is missed.
📋 Steps
Start with Process (Center), then Outputs/Customers, then Inputs/Suppliers.
📐 The 30,000ft View
Keep it simple. The "Process" column should only have 5-7 high-level steps.
🧠 Scope Definition
The first and last steps in the "Process" column define the exact boundaries of your project.
🎯 Reference Values
Inputs = Material/Info/Data needed. Outputs = Products/Services/Docs delivered.
🚀 Phase Relevance
Define: Sets the scope.
Measure: Identifies where to collect data (Inputs/Outputs).
