🧪 Chi-Square Test Logic & Interpretation
📐 Standard Equation
χ² = Σ [ (O - E)² / E ]

Where: O = Observed Frequency, E = Expected Frequency.

🧠 Interpretation Guide
• P < 0.05: Dependent (Link Found)
• P > 0.05: Independent (No Link)

Proven at 95% Confidence Level.

● The Question: Does factor X truly influence outcome Y? ● The Requirement: Counts/Frequencies only (Integers).
🔍 What Is It?
Tests if two categorical variables (e.g. Shift vs Defect Type) are related or independent.
⏱️ When To Use?
When analyzing discrete data (Counts like Pass/Fail) in a contingency table.
💡 Why Use It?
Proves that a pattern (e.g. Night shifts make more defects) is real and not random luck.
📋 Requirements
Count Data (Integers). Expected Frequency > 5 per cell. Random Sampling.
🎯 Reference Values
Critical Value for 2x2 table (1 df) = 3.841 at 95% Confidence Level.
🚀 Phase Relevance
Analyze: Find root causes.
Improve: Verify results.
⚖️ Degrees of Freedom
df = (Rows-1) * (Cols-1). For a 2x2 table, df = 1.
🛡️ Null Hypothesis (H₀)
Variable X and Variable Y are independent (No relationship).
