Yield Gauge Chart

CONTROL
"What gets measured, gets managed."

📜 Origin & Power

Visual Management (Andon) is a core pillar of the Toyota Production System. Gauge charts provide instant, "at-a-glance" status of whether a process is winning or losing, eliminating the need to decipher rows of data.

🤔 What is it?

A semi-circle chart (Speedometer) indicating current performance against defined Red/Yellow/Green zones.

💡 Why use it?

To evoke an emotional/action-based response. Red = Stop & Fix. Green = Keep Going.

🕒 When to use?

Control Phase (Dashboards, Weekly Reports, Shop Floor Boards).

📋 Pre-Requirements

Clear specification limits (LSL/USL) or targets.

👮 Strict Roles

Process Owner: Monitors the gauge daily.
Manager: Reacts to Red conditions.

🎮 How to Execute (Story Mode)
1
Set Limits
Define what is Good (Green) vs Bad (Red).
2
Input
Enter the current actual value.
3
React
If Red, initiate Root Cause Analysis.
