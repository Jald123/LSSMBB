Measurement System Analysis (MSA)

The bedrock of all data-driven decision making.

What is Gage R&R?

Gage R&R evaluates the Precision of a measurement tool. Before you trust process data, you must prove that the tool (machine) and the user (people) produce consistent results. If the Gage R&R fails (>30%), your data is noise and cannot be used for Cpk or SPC.

Repeatability (EV)

Equipment variation. Can the SAME person get the SAME result with the SAME gage on the SAME part?

Reproducibility (AV)

Appraiser variation. Can DIFFERENT people get the SAME result using the SAME tool?

Architecture Intelligence: Trust Your Data

1. Manufacturing: Micrometer Audit

Repeatability Error: Stickiness in the micrometer screw causes the technician to get 10.01, 10.05, and 9.98 on the same part. Fix: Recalibrate Tool.
Reproducibility Error: Technician A holds the tool tight, B holds it loose. A reads 10.0mm, B reads 10.2mm. Fix: Standardize SOP.

2. Resolution (ndC) Visualized

Low nDC (< 5): Like using a bathroom scale to measure yeast. You only see 1 or 2 buckets ("Heavy" or "Light"). Too blunt for 6-sigma.

High nDC (>= 5): Like a high-res digital monitor. You see 10+ distinct buckets of variation. Capable of detecting tiny process shifts.

×

Accuracy vs Precision

MSA Gage R&R specifically measures PRECISION (Consistency). A tool can be perfectly precise (hitting the same spot) but not accurate (off center). We fix accuracy with Calibration; we fix Precision with MSA.
