Accuracy vs Precision

The Marksman Analogy 🎯

Accuracy is hitting the bullseye (Bias). Precision is hitting the same spot every time (Variation). Gage R&R focus is specifically on PRECISION.

×

Trust Your Data Briefing 🧐

Ensure your measurement system is capable before making process decisions.

Repeatability (EV)

Variation when the SAME person measures the SAME part with the SAME gage. If this is high, the equipment is likely at fault.

Reproducibility (AV)

Variation when DIFFERENT people measure the SAME part. If this is high, training or SOPs are inconsistent.

The 10-30 Rule

  • < 10%: Excellent system.
  • 10 - 30%: Acceptable depending on application criticality.
  • > 30%: Unacceptable. Fix the measurement system first.

📚 Visual Training Examples

1. The Core Concept: Tool vs. People

Repeatability (Tool Issue): This occurs when a single person gets inconsistent results using the same tool on the same part. The variation is due to the tool itself being faulty. In the left panel, the broken caliper leads to different readings for the same technician.
Reproducibility (People Issue): This happens when different people get different results when measuring the same part, even with a good tool. The variation is due to different techniques. In the right panel, the two technicians hold the micrometer differently, leading to different measurements.

2. Daily Life Example: Baking Measurements

Repeatability (Tool Issue): A baker using a dented measuring cup will get a different amount of flour each time they scoop, even if they try to be consistent. The tool's flaw makes it unrepeatable.
Reproducibility (People Issue): Two different bakers might use a perfect measuring cup but have different techniques—one levels the flour, the other heaps it. Their results are not reproducible between them.

3. Healthcare Example: Blood Pressure Measurement

Repeatability (Tool Issue): A nurse using a blood pressure cuff with a sticky gauge will get erratic readings on the same patient. The faulty device makes the measurement unrepeatable.
Reproducibility (People Issue): Two different nurses measuring the same patient's blood pressure can get different results if their techniques vary (e.g., cuff tightness, placement over clothing). The measurement is not reproducible between operators.

4. nDC: Machine Part Validation

Low nDC (< 5): Your tool lacks resolution. Imagine using a crude wooden ruler to measure precision engine parts. The tool can only sort parts into 1 or 2 big buckets. It's too blunt to tell exactly how much your process is changing.
High nDC (≥ 5): Your tool has excellent resolution. Using a precision digital micrometer provides multiple decimal places, splitting the variation into 5 or more distinct data buckets, allowing you to accurately track tiny process shifts.

5. nDC: Measuring Ingredients

Low nDC (< 5): A baker guessing weight by holding a vague handful creates only 2-3 categories of data ("Too much", "Too little"). The measurement scale is far too coarse to consistently follow a precise recipe.
High nDC (≥ 5): Using a high-precision digital kitchen scale gives you highly distinct categories. The tool is sensitive enough to catch even a minor deviation before it ruins the batch.

6. nDC: Patient Monitoring

Low nDC (< 5): A crude 3-level face chart forces complex, nuanced patient data into only 3 rigid categories. It's impossible to see whether a patient is getting slightly better or slightly worse.
High nDC (≥ 5): A digital monitor provides a continuous, high-definition stream of exact data. It can easily differentiate between 70 BPM and 74 BPM, providing 5+ clear data buckets for real medical analysis.

🤔 What is MSA Gage R&R?

Measurement System Analysis (MSA) Gage R&R is a statistical study that evaluates the reliability of your measurement system. Before you analyze process data, you must first prove that the measurement tool and people producing that data are trustworthy. If the measurement system is flawed, every downstream decision is built on faulty data.

🔄 R = Repeatability (EV)

Can the SAME person get the SAME result when measuring the SAME part multiple times using the SAME tool?

If poor → Equipment is the problem (calibration, wear)

👥 R = Reproducibility (AV)

Can DIFFERENT people get the SAME result when measuring the SAME part with the SAME tool?

If poor → Training/SOP is the problem (technique, interpretation)

📊 The 10/30 Acceptance Rule

< 10%
EXCELLENT
Measurement system is reliable
10–30%
MARGINAL
Acceptable based on context
> 30%

🔢 nDC — Number of Distinct Categories

nDC tells you how many different "levels" of variation your measurement tool can actually detect. Think of it as resolution. Target: ≥ 5 categories. If nDC < 5, the tool is too coarse — like trying to weigh milligrams on a bathroom scale.

📋 When to Use This Tool

  • Before collecting baseline data in the Measure phase
  • After acquiring a new measurement device or method
  • When different operators produce inconsistent results
  • Before setting control chart limits or SPC monitoring
  • During process capability studies (Cp/Cpk) — invalid if MSA fails
