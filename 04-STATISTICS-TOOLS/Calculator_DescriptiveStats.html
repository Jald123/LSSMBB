📈 Descriptive Statistics Guide

Understand the true nature of your data: Center, Spread, and Shape.

🎯 Center (Tendency)

What: Where is the "middle" of the data? (Mean, Median, Mode).

How to Interpret:

  1. Mean (Average): Sum / Count. Best for Normal Data.
  2. Median (Middle): The exact middle value. Best for Skewed Data (e.g., Salaries).
  3. Comparison: If Mean > Median, data is skewed Right (Positive). If Mean < Median, Skewed Left.
⚠️ Important Consideration: Outliers pull the Mean aggressively. Never trust the Average alone if you have extreme values.

📏 Spread (Variation)

What: How consistent is the process? (Std Dev, Range, Variance).

How to Interpret:

  1. Std Dev (σ): Average distance of points from the center. Low = Consistent.
  2. Range: Max - Min. A quick check for extremes.
  3. CV (Coeff of Var): (StdDev / Mean). Allows you to compare variation between different units (e.g., Meters vs Kg).
⚠️ Important Consideration: A process can be "On Target" (Good Mean) but "High Variation" (Bad Std Dev). Use the Histogram to see the width.

🔔 Normality & Shape

What: Does the data follow the Bell Curve? (Anderson-Darling Test).

How to Interpret:

  1. P-Value: If P < 0.05, data is NOT Normal (Reject Null Hypothesis).
  2. Skewness: 0 = Symmetrical. +/- 0.5 is fairly symmetrical. +/- 1.0 is highly skewed.
  3. Kurtosis: Measures the "Peak". High Kurtosis = Sharp peak (Leptokurtic).
⚠️ Important Consideration: Most Stats Tests (T-Test, ANOVA, Cp/Cpk) ASSUME Normality. If P < 0.05, you must transform data or use Non-Parametric tests.

Strict Role Definitions

  • 🟢 Green Belt: Collects 30+ samples and checks Normality.
  • ⚫ Black Belt: Analyses Non-Normal data using Transformations (Box-Cox).
  • 👮 Process Owner: Uses Control Charts (Mean) for daily monitoring.

Box Plot (Spread & Outliers) ?
📦 Box Plot

What: Shows spread, center, and outliers at a glance.

Anatomy:
• Box: Middle 50% (IQR)
• Line in Box: Median
• Whiskers: Range (excl. outliers)
• Stars/Dots: Outliers (> 1.5×IQR)

Best For: Comparing groups or spotting extreme values.

Normal Probability Plot ?
📈 Normal Probability Plot (QQ)

What: Visual test for normality. Plots data vs theoretical normal quantiles.

Interpretation:
• Straight Line: Data is Normal ✅
• S-Shape: Heavy or light tails
• Banana Curve: Skewed data

Use When: Confirming assumptions for T-tests, ANOVA, etc.
