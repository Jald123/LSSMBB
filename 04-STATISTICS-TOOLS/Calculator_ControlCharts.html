PHASE: CONTROL

I-MR Control Charts SPC ENGINE

Monitor Stability. Detect Signals. Differentiate Signal from Noise.

🔍 What Is It?
Two plots tracking individual values (I-Chart) and the range between neighbors (MR-Chart).
⏱️ When To Use?
For continuous data where samples are collected one by one (e.g. daily revenue, batch pH).
💡 Why Use It?
Tells you if variation is "Common Cause" (Normal) or "Special Cause" (Actionable).
📋 Requirements
Continuous data. Normality assumed. Data must be in time-order.
📐 Standard Equation
UCL = x̄ + 2.66 * MR̄
LCL = x̄ - 2.66 * MR̄
🧠 Interpretation
Points within limits = Stable.
Points outside = Unstable (Check outlier).
🎯 Reference Values
Nelson Rule #1: Any point > 3σ from center line is a failure.
🛡️ Nelson Rules
Rule 1: Point > 3σ
Rule 2: 9 points same side
Rule 3: 6 points trending
