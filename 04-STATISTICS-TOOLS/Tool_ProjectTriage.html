Scope Impact

Problem Definition Canvas

Defining The "What"
Focus on the measurable defect or pain point, not the lack of a solution.
⭐ IDEAL EXAMPLES:
  • "30-Day Readmission Rate" (Healthcare)
  • "First Pass Yield %" (Manufacturing)
  • "Invoice Processing Cycle Time" (Transactional)
Defining The "Where"
Be specific about boundaries. Avoid "Global" scope for standard belts.
⭐ IDEAL EXAMPLES:
  • "Ward 3 - Oncology Unit"
  • "Assembly Line 4 - Paint Shop"
  • "US East Coast Accounts Payable"
Defining The "When"
When did the issue start? Essential for baseline data comparison.
⭐ IDEAL EXAMPLES:
  • "Since Q1 2024"
  • "Following the SAP Upgrade in June"
  • "Past 12 Month Rolling Average"
Defining "Baseline"
Current performance. If you don't have this, you have a 'Just Do It' data collection task first.
⭐ IDEAL EXAMPLES:
  • "15% Error Rate"
  • "4.5 Hours Average"
  • "$50,000 Waste/Month"
Defining "Target"
The Goal state. Must be realistic. Avoid "Zero defects" unless statutory.
⭐ IDEAL EXAMPLES:
  • "Reduce to < 5% Error Rate"
  • "Improve to 95% Yield"
  • "Cut Cycle time by 50%"
Defining "Deadline"
Standard DMAIC projects run 3-6 months.
⭐ IDEAL EXAMPLES:
  • "By Q4 2024"
  • "Within 6 months"
  • "Before next Fiscal Year"

Decrease [What] from [Baseline] to [Target] by [Timeline].
