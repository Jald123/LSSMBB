🧙 Knowledge Base

Hypothesis Testing

What: A statistical method to determine if a difference in data is "Real" or just random luck.
Why: "In God we trust, all others must bring data." Don't guess if the new machine is faster—prove it with 95% confidence.
When: Analyze Phase. When comparing Before vs After, Shift A vs Shift B, or Suppliers.

The P-Value (The "Big" Key)

If P is Low, the Null must Go!
(P < 0.05)=Significant Difference exists.
We found something!
If P is High, the Null can Fly.
(P > 0.05) = No Significant Difference.
Nothing changed. Random noise.
