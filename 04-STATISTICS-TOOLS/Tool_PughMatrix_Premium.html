Pugh Matrix ANALYZE

Decision Matrix Analysis. Concept Selection. Which solution wins?

🔍 What Is It?
A scoring matrix used to compare multiple design alternatives against a baseline.
⏱️ When To Use?
During IMPROVE phase when selecting the best solution from several candidates.
💡 Why Use It?
To make objective, multi-criteria decisions instead of relying on gut feelings.
📋 Requirements
1 Baseline design, 3+ criteria, 2+ alternative concepts. Use weights for precision.
📐 Scoring Key
+1: Better | 0: Same | -1: Worse than Baseline.
🧠 Interpretation
The concept with the highest Weighted Total is the strongest candidate.
🎯 Reference
Stuart Pugh (1981). Ideal for iterative concept refinement.
🚀 Phase Relevance
Analyze: Compare options.
Improve: Converge on best.
