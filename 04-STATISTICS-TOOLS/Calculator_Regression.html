Predict Outcomes. Identify Relationships. How does X truly impact your Y?

🔍 What Is It?
Models the mathematical relationship between an Input (X) and an Output (Y).
⏱️ When To Use?
To prove correlation (e.g. Does increasing Oven Temp really increase Cookie Hardness?).
💡 Why Use It?
Builds a prediction model (Y = mX + c) so you can control the outcome.
📋 Requirements
Continuous Data. Linear Relationship. Normal Residuals. No Autocorrelation.
📐 Standard Equation
Y = β0 + β1*X + ε
🧠 Interpretation
R-Squared > 80% = Strong Model.
P-Value < 0.05=Relationship is Real.
🎯 Reference Values
Correlation (r) from -1 (Perfect Negative) to +1 (Perfect Positive).
🚀 Phase Relevance
Analyze: Verify root causes.
Improve: optimize settings.
